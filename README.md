# Marbetes Cítricos A4 - Vivero "El Paraisal"

Aplicación web para generación, personalización e impresión de marbetes / tarjetas certificadas para plantas cítricas del **Vivero Cítrico "El Paraisal"** de Sebastián Canaglia (Chajarí, Entre Ríos).

## Características

- **Diseño Marbete Oficial**: Incluye datos del vivero, normativa de certificación (Ley Nº 20.247 - Art. 9, R.N.C. y F.S. Nº 11566 / J1) y campos de Especie, Cultivar, Portainjerto, DAV Nº, Categoría, Procedencia y Contenido neto.
- **Sin textura digital**: Fondo plano amarillo o blanco, ideal para imprimir sobre el papel marbete real.
- **Disposición en 1 Columna**: Exactamente hasta 4 tarjetas por hoja A4, aprovechando todo el ancho disponible para que los nombres de variedades y portainjertos se lean completos sin cortes.
- **Código QR independiente**: Cada tarjeta cuenta con su código QR en el lateral izquierdo (con generación por texto/URL, subida de imagen o pegado directo desde el portapapeles con `Ctrl + V`).
- **Descarga en PNG**: Botones directos para descargar la tarjeta activa o la hoja A4 completa en formato PNG de alta resolución.
- **Impresión Directa / Guardar como PDF**: Optimizado para hojas A4 en una sola columna.

## Publicación en GitHub Pages

Este proyecto está 100% listo para publicarse en **GitHub Pages** de forma gratuita:

1. Crea un repositorio en tu cuenta de GitHub (por ejemplo: `marbetes-vivero`).
2. Sube estos archivos a la rama principal (`main`).
3. En GitHub, ve a **Settings** > **Pages**.
4. En **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `root`
   - Haz clic en **Save**.
5. En unos segundos, tu sitio estará disponible en:
   `https://<tu-usuario>.github.io/<tu-repositorio>/`

## Uso Local

Simplemente abre el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox). No requiere servidores ni dependencias adicionales.
